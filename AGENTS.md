# Public Mirror Instructions

## Repository role

- This repository is a sanitized, one-way public mirror of Apex's authoritative
  private contracts repository. It is not an independent protocol fork.
- Published `src/**`, eligible non-deployment `test/**`, vendored contract
  libraries, and `foundry.lock` must match the selected private
  source commit exactly.
- Do not introduce independent Solidity changes here. Protocol changes originate
  in the private authority and arrive through its public-mirror export workflow.
- All first-party scripts and configuration, broadcasts, operational records,
  operational/SDK integration tests, first-party docs and audit notes, operator tooling,
  credentials, private reports, and internal agent material are
  intentionally absent. Do not recreate or request them merely to make the trees
  look identical.
- Public-only README, Foundry configuration, CI, ignore rules, and this file are
  generated by the private export workflow and may intentionally differ.
- If asked whether the repositories are synchronized, compare this public
  snapshot to the private source commit named by the publication record; do not
  compare unrelated latest commit hashes or infer drift from excluded paths.
